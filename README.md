#### Requisitos:
- Dispositivo capaz de rodar Termux;
- Uma conta válida no GitHub;
- Acesso à internet.

---

#### Primeiros passos:

Para começar, é necessário instalar o Termux, de preferência pelo F-Droid, pois a versão disponível na Play Store está desatualizada. Entretanto, é possível baixar o arquivo APK diretamente pelo repositório do Termux no GitHub.

Link do F-Droid: https://f-droid.org/pt_BR/

Link do repositório do Termux: https://github.com/termux/termux-app
